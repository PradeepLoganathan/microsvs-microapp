# Demo Script — Microservices + Micro-App Banking Demo

## Pre-Demo Setup (15 min before)

```bash
# 1. Clean start
./scripts/run-all.sh --clean
./scripts/run-all.sh

# 2. Verify all services are running (check the summary table)

# 3. Build and publish micro-apps
./scripts/build-microapps.sh
./scripts/publish-microapps.sh

# 4. Start mobile app
cd mobile/banking-shell && npm install && npx ionic serve

# 5. Open http://localhost:4200 in Chrome
# 6. Keep a terminal ready for manifest editing
# 7. Verify manifest is on v1:
curl -s http://localhost:8079/microfrontends/manifest?channel=demo | python3 -m json.tool
```

## Talk Track

### Act 1: The Problem (2 min)

> "Imagine a traditional banking monolith. Every feature change — even a small UI tweak — requires a full release cycle: build, test, app store review, user adoption. We're going to break that model today."

> "What I'm going to show you is a banking app where:
> - The backend is decomposed into independent microservices running on Akka
> - The mobile app loads feature UIs dynamically — no app store needed
> - And we have an agentic AI service that analyzes your spending"

### Act 2: The Architecture (3 min)

Show the architecture diagram (README or slide).

> "We have four backend microservices, each an independent Akka SDK service:
> - **Statement Service** holds your transaction history
> - **Analysis Service** has an AI agent that categorizes spending and generates insights
> - **Product Service** is a catalog of financial products
> - **Recommendation Service** ties it all together — it looks at your spending patterns and recommends relevant products"

> "On the frontend, we have an Ionic Angular shell that loads micro-apps dynamically from a CDN, based on a manifest. Each micro-app is a self-contained Web Component."

### Act 3: Live Demo — The App (3 min)

Switch to browser showing the banking app.

> "Here's our mobile banking app. Let me walk through it."

1. **Home tab**: "Account overview for our demo user. Balance, recent activity — standard stuff."

2. **Statements tab**: "This micro-app was loaded dynamically. It shows three months of statements. Let me click into December..."
   - Show transactions: "Travel-heavy month — flights, hotels, Uber rides."

3. **Analysis tab**: "This is where it gets interesting. The analysis service categorized all transactions and found that Travel is 45% of December's spending."
   - Point out categories and insights.

4. **Recommendations tab**: "Based on the spending analysis, the system recommends a Travel Rewards card. That recommendation was generated by rules running against the analysis data — deterministic, explainable."

### Act 4: The Agentic AI (3 min)

Switch to IDE showing `TransactionAnalysisAgent.java`.

> "Let me show you what's under the hood. This is an Akka Agent — a first-class construct in the Akka SDK."

Point out:
- `extends Agent` — "It's a proper Akka component, not a wrapper"
- `@FunctionTool` annotations — "These are tools the agent can call: fetch transactions, categorize them, persist results"
- The system message — "This tells the agent its role: financial analyst"
- `effects().systemMessage().userMessage().thenReply()` — "This is the agentic loop"

> "Right now we're running in heuristic mode — deterministic categorization, no API key needed. Flip a config flag, and the same service uses the LLM through these exact tools."

### Act 5: The Wow Moment — Live Update (3 min)

> "Now for the key moment. I'm going to update the Statement Analysis feature — live, without touching the backend, without an app store."

**Step 1**: "Notice Statement Analysis shows v1 — a basic category table."

**Step 2**: Open `platform/microfrontend-registry/manifest.json` in the editor.

> "I'm changing one line — the version and URL for StatementAnalysis. From 1.0.0 to 2.0.0."

```json
{
  "name": "StatementAnalysis",
  "version": "2.0.0",
  "remoteEntry": "http://localhost:8090/statement-analysis/2.0.0/main.js"
}
```

**Step 3**: Save the file.

**Step 4**: Refresh the browser.

> "And there it is — v2. We now have a 'Top Merchants' section, the layout changed, and there's a v2 badge. The backend didn't restart. The app shell didn't change. We just pointed to a new bundle."

> "In production, this manifest update would be a deployment step — push a new bundle to CDN, update the manifest in a config service, and every user gets the new feature on their next app open."

### Act 6: Wrap-Up (1 min)

> "To summarize:
> - Microservices on Akka give us independent scaling and deployment
> - The Akka Agent construct brings AI capabilities as a first-class building block
> - Micro-app delivery lets us update individual features without full app releases
> - Everything you saw runs locally — no cloud, no containers, just Maven and npm"

## Recovery Steps

**If a service doesn't start:**
```bash
# Check logs
cat logs/<service>.log
# Restart just that service
cd backend/<service> && mvn compile exec:java
```

**If the mobile app won't load micro-apps:**
```bash
# Check CDN is running and has files
curl http://localhost:8090/statement-details/1.0.0/main.js | head -1
# Check manifest
curl http://localhost:8079/microfrontends/manifest?channel=demo
```

**If v2 update doesn't show:**
- Make sure you saved the manifest file
- Hard refresh the browser (Ctrl+Shift+R)
- Check browser console for script loading errors
- Verify CDN has v2: `curl http://localhost:8090/statement-analysis/2.0.0/main.js | head -1`
